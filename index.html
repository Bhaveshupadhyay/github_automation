Quick Deployment Guide

Get your Slackbot Autonomous Developer running in under 5 minutes.

⚡ 1-Command Zero-Clone Setup Wizard

No manual repository cloning required! Run this single command inside your repository or project folder to configure your entire autonomous AI developer pipeline automatically:

npx autopr-slack
  • Step 1: Preflight environment & target repo diagnostics.
  • Step 2: Deploys Cloudflare Worker edge webhook (sub-50ms routing).
  • Step 3: Generates 1-click slack-app-manifest.json.
  • Step 4: Provisions GitHub & Cloudflare secrets via gh CLI.
  • Step 5: Injects reusable GitHub Actions execution workflow (using uvx).

📱 1-Click Slack App Manifest

The setup wizard generates slack-app-manifest.json with pre-configured slash commands (/code), event subscriptions, and OAuth scopes.

  1. Go to api.slack.com/apps and click Create New App.
  2. Select From an app manifest and choose your Slack workspace.
  3. Paste the contents of slack-app-manifest.json and click Create.
  4. Click Install to Workspace and copy your Bot Token (xoxb-...).
npx autopr-slack manifest

🐍 PyPI Engine & Modular CLI Subcommands

The core Antigravity execution engine runs instantly via uvx with zero installation:

uvx --from github-automation-ai autopr

You can also execute individual CLI modules on-demand:

npx autopr-slack workflow && npx autopr-slack secrets
